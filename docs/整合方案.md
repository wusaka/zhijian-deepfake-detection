### 待完成步骤

1. **启动 Docker Desktop** 应用
2. **启动基础设施**
   ```powershell
   cd Video-Detection-System-main
   docker-compose -f docker-compose-infra.yml up -d
   ```
3. **初始化数据库**
   ```powershell
   .\scripts\init-database.ps1
   ```
4. **编译 Java 后端**（新终端需先加载环境变量）
   ```powershell
   $env:JAVA_HOME = "E:\java\jdk-17.0.18+8"
   $env:Path = "$env:JAVA_HOME\bin;E:\java\apache-maven-3.9.14\bin;$env:Path"
   mvn clean package -DskipTests
   ```
5. **启动 6 个 Java 微服务**
6. **启动 React 前端**
   ```powershell
   cd frontend
   npm install
   npm run dev   # → http://localhost:5173
   ```

> Worker Service 的配置 `ai.service.url: http://localhost:5000` 已经指向桥接服务，**不需要修改**。

## 完整启动顺序

```
1. Docker Desktop (手动打开)
2. docker-compose -f docker-compose-infra.yml up -d  (PostgreSQL/Kafka/Redis)
3. python bridge_service.py                           (M2F2 AI, 端口5000)
4. java -jar auth-service.jar                         (端口9001)
5. java -jar video-service.jar                        (端口9002)
6. java -jar worker-service.jar                       (端口9003)
7. java -jar detection-service.jar                    (端口9004)
8. java -jar websocket-service.jar                    (端口9005)
9. java -jar audit-service.jar                        (端口9006)
10. npm run dev                                        (React, 端口5173)
```
