## 一、项目简介

「智鉴系统」是一个 **AI 驱动的视频/图片内容安全检测平台**，由以下两个开源项目整合而成：

| 项目 | 说明 | 技术栈 |
|------|------|--------|
| **Video-Detection-System** | Web 平台（前端 + 后端微服务） | React + Spring Boot 3.2 + PostgreSQL + Kafka |
| **M2F2_Det** | AI 深度伪造检测模型 | PyTorch + Transformers + Flask |

### 整合目标

用户通过 Web 界面上传图片/视频 → Java 后端创建检测任务 → Worker 服务调用 M2F2_Det AI 模型 → 返回真/伪判定结果及置信度 → 前端展示检测报告。

## 四、完整部署步骤

### 4.1 首次部署

#### 步骤 1：启动 Docker Desktop

确保 Docker Desktop 已安装并运行。任务栏右下角应出现 Docker 鲸鱼图标。

#### 步骤 2：启动基础设施容器

```powershell
cd Video-Detection-System-main
docker-compose -f docker-compose-infra.yml up -d
```

验证容器状态：
```powershell
docker ps
```

应看到 4 个容器运行中：
| 容器名 | 镜像 | 端口 |
|--------|------|------|
| video-detection-db | postgres:15-alpine | 15432 → 5432 |
| video-detection-redis | redis:7.0-alpine | 6379 → 6379 |
| video-detection-kafka | cp-kafka:7.5.0 | 19092 → 9092 |
| video-detection-zookeeper | cp-zookeeper:7.5.0 | 2181 → 2181 |

#### 步骤 3：初始化数据库角色

首次部署需要插入角色数据（仅需执行一次）：

```powershell
docker exec -i video-detection-db psql -U admin video_detection -c "
INSERT INTO roles (id, name, description, created_at, updated_at) VALUES 
(1, 'ROLE_USER', '普通用户', NOW(), NOW()),
(2, 'ROLE_ADMIN', '管理员', NOW(), NOW())
ON CONFLICT DO NOTHING;
"
```

#### 步骤 4：编译 Java 后端

```powershell
cd Video-Detection-System-main
$env:JAVA_HOME = "E:\java\jdk-17.0.18+8"
$env:Path = "$env:JAVA_HOME\bin;E:\java\apache-maven-3.9.14\bin;$env:Path"
mvn clean package -DskipTests -s settings.xml
```

编译成功应显示：
```
[INFO] BUILD SUCCESS
[INFO] Total time: ~30 s
```

#### 步骤 5：启动 AI Bridge 服务

```powershell
cd M2F2_Det-main
$env:HF_HUB_OFFLINE="1"
conda run -p M2F2_Det-main\m2f2_conda --live-stream python -u bridge_service.py
```

等待输出以下内容（约 30 秒）：
```
✅ M2F2Det model loaded successfully
📊 GPU Memory: ~4.19 GB
🚀 Bridge service running on http://0.0.0.0:5000
```

> **注意**：此窗口需保持打开，不要关闭。

#### 步骤 6：启动 Java 微服务

新开一个 PowerShell 窗口：

```powershell
cd Video-Detection-System-main
$env:JAVA_HOME = "E:\java\jdk-17.0.18+8"
$j = "$env:JAVA_HOME\bin\java.exe"

# 依次启动 6 个微服务
@('auth-service','video-service','detection-service',
  'worker-service','websocket-service','audit-service') | ForEach-Object {
    Start-Process -FilePath $j -ArgumentList "-jar","$_\target\$_-0.0.1-SNAPSHOT.jar" -WindowStyle Minimized
    Write-Host "Started: $_"
}
```

等待约 20 秒让所有服务启动完成。

#### 步骤 7：启动前端

```powershell
cd Video-Detection-System-main\frontend
npx vite --port 3000
```

应显示：
```
VITE v7.3.0 ready in 283 ms
➜ Local: http://localhost:3000/
```

#### 步骤 8：访问系统

浏览器打开 **http://localhost:3000**

## 九、常见问题排查

### Q1: 端口被占用

**症状**：服务启动失败，提示 `Address already in use`

**解决**：
```powershell
# 查看占用端口的进程
netstat -ano | findstr :9001

# 杀掉进程
taskkill /f /pid <PID>
```

### Q2: Docker 容器启动失败

**症状**：`docker-compose up -d` 报错

**解决**：
1. 确保 Docker Desktop 已启动（绿色图标）
2. 等待 Docker 完全启动后再执行命令
3. 如果端口冲突，检查 `docker-compose-infra.yml` 中的端口映射

### Q3: AI 模型加载失败

**症状**：bridge_service.py 报错 `model not found`

**解决**：
1. 检查 `M2F2_Det-main\checkpoints\` 下是否有模型文件
2. 确保设置了 `$env:HF_HUB_OFFLINE="1"` 使用离线模式
3. 检查 GPU 驱动是否支持 CUDA 12.1

### Q4: Java 编译失败

**症状**：`mvn package` 报错

**解决**：
```powershell
# 确保 JAVA_HOME 正确
$env:JAVA_HOME = "E:\java\jdk-17.0.18+8"
java -version  # 应显示 17.0.18

# 使用项目自带的 settings.xml
mvn clean package -DskipTests -s settings.xml
```

### Q5: 登录返回 403

**症状**：浏览器登录时无反应或报 403 错误

**解决**：
1. 确保 auth-service 是用最新编译的 jar 启动的
2. 确保 roles 表有数据：
```powershell
docker exec -i video-detection-db psql -U admin video_detection -c "SELECT * FROM roles;"
```
3. 如果为空，执行步骤 4.1 步骤 3 插入角色

### Q6: 前端 Vite 端口 5173 被占用

**症状**：`npm run dev` 报 `EACCES: permission denied`

**解决**：使用其他端口
```powershell
npx vite --port 3000
```

## 十一、技术要点

### 11.1 M2F2_Det 模型

- **论文**：M2F2-Det: A Multi-Modal Framework for Face Forgery Detection
- **模型结构**：基于 LLaVA (Large Language-and-Vision Assistant)
- **输入**：RGB 图片（任意大小, 自动 resize 到 336×336）
- **输出**：二分类 logits [real_score, fake_score]
- **推理方式**：直接使用 M2F2Det.forward() 的 deepfake head 输出，跳过 LLM 文本生成，推理快且准

### 11.2 微服务通信

```
用户上传图片 → video-service 保存文件
                 → Kafka 发送 DetectionTaskEvent
                 → worker-service 消费消息
                 → HTTP 调用 bridge_service :5000
                 → M2F2_Det GPU 推理
                 → Kafka 发送 DetectionCompletedEvent
                 → detection-service 更新任务状态
                 → websocket-service 推送前端通知
```

### 11.3 安全机制

- **JWT 认证**：所有 API 请求需携带 `Authorization: Bearer <token>`
- **公开路径**：`/api/auth/login`, `/api/auth/register`, `/api/health`
- **CORS**：允许 `localhost:3000` 和 `localhost:5173`
- **密码规则**：至少 8 位，需包含大小写字母、数字、特殊字符
